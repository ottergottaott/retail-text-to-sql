What is implemented

Open WebUI and CLI share a FastAPI/LangGraph backend. Gemini plans analysis and reviews reports. BigQuery execution is read-only, scoped to the user and bounded by time and scan budgets. Hybrid retrieval supplies versioned Golden Trios.

Reports have tables, supported charts and inspectable SQL. They survive chat deletion. Preferences persist across chats; feedback passing automatic evidence/access/quality checks becomes scoped knowledge. CEO tone changes use an automatic gate with version rollback.
