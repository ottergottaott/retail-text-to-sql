Architecture

Original records stay in the application. Sanitized copies go to external models.

1. Analysis request

2. Indexing — explicit administrator operation

Indexing prepares document vectors when published examples or the embedding/privacy version change. It does not run on each question; originals remain unchanged.

Storage: PostgreSQL holds original Trios and embedding JSON records; similarity is computed in Python. pgvector is a possible scaling extension, not installed. Publication quality checks are separate from retrieval.

3. Search — on each question

Access filtering comes before both rankings. No unrestricted top-k search followed by permission filtering. The current implementation filters candidates in Python before computing scores.

4. Automatic improvement

One API worker polls persisted jobs. External evaluation receives sanitized copies through the configured model provider. Failed gates retain feedback and the previous tone; dependency retries are bounded. Corrections require an independently approved definition. Tone supports rollback. Workflow and limits.

Local PII recognition can miss unusual or obfuscated values and overmask safe text. WebUI retains original messages. Do not enter real PII into this prototype. Fresh live Gemini/BigQuery acceptance remains pending.
